¿Qué tipo de expediente vas a registrar?
Cada tipo de proceso tiene sus propios campos, fechas y plazos — selecciona uno para continuar. El formulario del siguiente paso se ajusta automáticamente.
Declarativo · Ordinario
Reclamos entre partes de mayor cuantía (contractual, daños y perjuicios). Audiencia preliminar 20–60 días.

Trámites breves: lanzamientos por intruso o por mora. Audiencia preliminar 10–20 días.
